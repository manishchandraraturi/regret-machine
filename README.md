# The Regret Machine

A browser game for the CMRIT x Intel "1 Million Minds" challenge. Pick a laptop on looks and price, then live with it for 3 years in 3 minutes.

Status: see docs/progress.md. Public URL: (added in P12).

## Run
```
npm ci
npm run dev
npm run test
npm run build
```

## Claims policy
Every Intel number on screen comes from `src/data/claims.json` with a source and baseline, and is marked "Intel-claimed, up to". Scenes are illustrations, not measurements.
