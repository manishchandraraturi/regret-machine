# Demo script for the Intel jury (3 minutes, timed)

Goal: the jury remembers one line: "the sale sticker aged". Rehearse twice. Have the fallback video (DEL-05) ready on a phone.

| Time | Who | Say / do |
|---|---|---|
| 0:00 | A | "Every Gen Z shopper already uses AI. In a store they still buy on price and colour. So we let them make that exact mistake." Hand the screen to a juror. |
| 0:15 | Juror plays | Attract > pick a laptop and a use > Buy it. Stay silent. |
| 0:35 | B | Point at the Year flip: "Watch the flyer age." |
| 0:40 | Juror plays | Scenes run. Narrate only the reveal: "Same moment, on an Intel Core Ultra Series 3 laptop." Point at the tag: "Intel-claimed, up to, with the baseline." |
| 1:50 | A | Receipt: "That is the regret score. It comes from what the player saved, not from a random number." |
| 2:05 | B | Fair Fight: "We show where rivals lead too, like the AI chip number on the box. We want trust, not hype." |
| 2:20 | A | Result + Staff screen: "The shopper walks to the sales associate with a plain-words ask list. That is the next step." Show QR and the share card. |
| 2:40 | Capt | Tech in 20 seconds: static site, no backend, no data collected, works with weak store Wi-Fi, English and Hindi, kiosk reset after 60 s idle. |
| 3:00 | Close | "Buy it today. See how it ages." |

## Likely jury questions
- "Is the decoy a real brand?" No. Fictional archetype. We never name a competitor laptop as the bad one.
- "Where do the numbers come from?" claims.json, each row has source, baseline, conditions. Scenes are labelled Illustration.
- "Does it use the NPU live?" No. A browser game cannot honestly claim that, so we illustrate and say so.
- "Why Hindi?" LFR walk-ins are not all English first.
- "How does it make people buy?" Regret aversion plus a concrete ask list for the store team.
